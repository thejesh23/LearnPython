# 03 · Operators

Arithmetic, comparisons, logic, identity, membership and the walrus.

Read the files in this order; each one runs on its own:

| # | File | What it teaches |
|---|------|-----------------|
| 1 | [`arithmetic.py`](arithmetic.py) | Arithmetic operators, including the two Python adds to the usual set. |
| 2 | [`comparison.py`](comparison.py) | Comparison operators — and Python's chaining, which most languages lack. |
| 3 | [`logical.py`](logical.py) | `and`, `or`, `not` — words, not symbols, and they return operands. |
| 4 | [`identity_and_membership.py`](identity_and_membership.py) | `is` / `is not` and `in` / `not in`. |
| 5 | [`walrus_operator.py`](walrus_operator.py) | `:=` — the walrus operator: assign *and* produce a value in one expression. |

```bash
python3 basics/03_operators/arithmetic.py
```
