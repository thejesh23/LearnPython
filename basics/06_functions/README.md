# 06 · Functions

Parameters of every kind, scope, closures, recursion, decorators, docstrings.

Read the files in this order; each one runs on its own:

| # | File | What it teaches |
|---|------|-----------------|
| 1 | [`basic_function.py`](basic_function.py) | Defining and calling functions. |
| 2 | [`default_arguments.py`](default_arguments.py) | Default parameter values — and the one famous trap. |
| 3 | [`args_and_kwargs.py`](args_and_kwargs.py) | `*args` and `**kwargs` — variadic parameters, and the unpacking operators. |
| 4 | [`keyword_and_positional_only.py`](keyword_and_positional_only.py) | Keyword-only (`*`) and positional-only (`/`) parameters. |
| 5 | [`docstrings_and_help.py`](docstrings_and_help.py) | Docstrings, help() and inspect: documentation that lives inside the code. |
| 6 | [`lambdas.py`](lambdas.py) | `lambda` — a small anonymous function, limited to a single expression. |
| 7 | [`higher_order_functions.py`](higher_order_functions.py) | Higher-order functions: functions that take or return other functions. |
| 8 | [`closures_and_scope.py`](closures_and_scope.py) | Closures and the LEGB scope rule. |
| 9 | [`decorators.py`](decorators.py) | Decorators — a function that wraps another function. |
| 10 | [`recursion.py`](recursion.py) | Recursion: a function that solves a problem by calling itself on a smaller piece. |

```bash
python3 basics/06_functions/basic_function.py
```
