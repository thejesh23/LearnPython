# 21 · Pythonic code

The idioms, style and habits that make Python code read well.

Read the files in this order; each one runs on its own:

| # | File | What it teaches |
|---|------|-----------------|
| 1 | [`zen_of_python.py`](zen_of_python.py) | The Zen of Python — `import this`, and what a few of its lines mean in code. |
| 2 | [`idiomatic_loops.py`](idiomatic_loops.py) | Idiomatic loops — before/after pairs that say what they mean. |
| 3 | [`eafp_vs_lbyl.py`](eafp_vs_lbyl.py) | EAFP versus LBYL — two ways to deal with things that might not work. |
| 4 | [`common_mistakes.py`](common_mistakes.py) | Common Python mistakes — each one shown failing, then fixed. |
| 5 | [`style_and_pep8.py`](style_and_pep8.py) | Style and PEP 8 — writing code that other people (and future you) can read. |

```bash
python3 basics/21_pythonic_code/zen_of_python.py
```
