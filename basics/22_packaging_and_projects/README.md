# 22 · Packaging and projects

Virtual environments, installing packages, pyproject.toml and project layout.

Read the files in this order; each one runs on its own:

| # | File | What it teaches |
|---|------|-----------------|
| 1 | [`virtual_environments.py`](virtual_environments.py) | Virtual environments: a private place to install packages for one project. |
| 2 | [`installing_packages.py`](installing_packages.py) | Installing packages with pip, pinning them, and checking what is installed. |
| 3 | [`pyproject_and_packages.py`](pyproject_and_packages.py) | Turning a folder of code into a package other people can install. |
| 4 | [`project_layout_and_tests.py`](project_layout_and_tests.py) | How a real project is laid out, and how its tests are found and run. |

```bash
python3 basics/22_packaging_and_projects/virtual_environments.py
```
