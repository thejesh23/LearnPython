# 01 · Variables

Names, values, and how assignment really works in Python.

Read the files in this order; each one runs on its own:

| # | File | What it teaches |
|---|------|-----------------|
| 1 | [`assignment.py`](assignment.py) | A variable is a name for a value the computer holds in memory. |
| 2 | [`multiple_assignment.py`](multiple_assignment.py) | Assigning several names at once — and taking values back apart. |
| 3 | [`constants_and_naming.py`](constants_and_naming.py) | Python has no `const`. It has a naming convention instead. |

```bash
python3 basics/01_variables/assignment.py
```
