# 14 · Testing

Checking your code automatically, from `assert` to `unittest.mock`.

Read the files in this order; each one runs on its own:

| # | File | What it teaches |
|---|------|-----------------|
| 1 | [`assert_and_doctest.py`](assert_and_doctest.py) | The two lightest ways to check code: `assert` and doctest. |
| 2 | [`unittest_basics.py`](unittest_basics.py) | `unittest` — Python's built-in test framework. |
| 3 | [`mocking_basics.py`](mocking_basics.py) | `unittest.mock` — stand-ins for things a test should not really touch. |

python3 basics/14_testing/assert_and_doctest.py
