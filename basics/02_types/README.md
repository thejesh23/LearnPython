# 02 · Types

Numbers, text, truth values, `None`, converting between them, and type hints.

Read the files in this order; each one runs on its own:

| # | File | What it teaches |
|---|------|-----------------|
| 1 | [`int_and_float.py`](int_and_float.py) | `int` and `float` — Python's two everyday number types. |
| 2 | [`strings_type.py`](strings_type.py) | `str` — an immutable sequence of Unicode characters. |
| 3 | [`booleans_and_none.py`](booleans_and_none.py) | `bool` and `None` — truth and absence. |
| 4 | [`type_conversion.py`](type_conversion.py) | Converting between types — explicitly, because Python refuses to guess. |
| 5 | [`type_hints.py`](type_hints.py) | Type hints — documentation the tools can check. |
| 6 | [`decimal_and_fractions.py`](decimal_and_fractions.py) | Exact arithmetic: why floats drift, and what to use instead. |

```bash
python3 basics/02_types/int_and_float.py
```
