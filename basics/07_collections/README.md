# 07 · Collections

Lists, tuples, dicts and sets, comprehensions, copying, sorting, queues.

Read the files in this order; each one runs on its own:

| # | File | What it teaches |
|---|------|-----------------|
| 1 | [`list_basics.py`](list_basics.py) | `list` — an ordered, mutable, growable sequence. |
| 2 | [`tuples.py`](tuples.py) | `tuple` — an immutable sequence, and Python's lightweight record. |
| 3 | [`dict_basics.py`](dict_basics.py) | `dict` — key/value mapping with O(1) average lookup. |
| 4 | [`set_basics.py`](set_basics.py) | `set` — an unordered collection of unique, hashable values. |
| 5 | [`comprehensions.py`](comprehensions.py) | Comprehensions — build a collection from an iterable in one expression. |
| 6 | [`sorting.py`](sorting.py) | Sorting — `sorted()`, `.sort()`, and the `key` function. |
| 7 | [`copying_and_references.py`](copying_and_references.py) | References, shallow copies, and deep copies. |
| 8 | [`dict_patterns.py`](dict_patterns.py) | Everyday dict patterns beyond the basics. |
| 9 | [`stacks_and_queues.py`](stacks_and_queues.py) | Stacks, queues and priority queues with list, deque and heapq. |

```bash
python3 basics/07_collections/list_basics.py
```
