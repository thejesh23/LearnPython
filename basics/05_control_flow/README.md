# 05 · Control flow

Making decisions and repeating work: `if`, `for`, `while`, `match`.

Read the files in this order; each one runs on its own:

| # | File | What it teaches |
|---|------|-----------------|
| 1 | [`if_elif_else.py`](if_elif_else.py) | `if` / `elif` / `else` — branching, and Python's use of indentation. |
| 2 | [`for_loop.py`](for_loop.py) | `for` — Python's loop iterates over *items*, not over an index. |
| 3 | [`range_and_enumerate.py`](range_and_enumerate.py) | `range`, `enumerate`, `zip`, `reversed` — the loop helpers. |
| 4 | [`while_loop.py`](while_loop.py) | `while` — loop until a condition goes false. |
| 5 | [`break_continue_else.py`](break_continue_else.py) | `break`, `continue`, and the loop `else` clause almost nobody knows. |
| 6 | [`match_statement.py`](match_statement.py) | `match` (3.10+) — structural pattern matching, not a C-style switch. |

```bash
python3 basics/05_control_flow/if_elif_else.py
```
