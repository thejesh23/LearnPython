# 13 · The standard library

The batteries you will use every week: collections, functools, datetime, re, logging.

Read the files in this order; each one runs on its own:

| # | File | What it teaches |
|---|------|-----------------|
| 1 | [`collections_module.py`](collections_module.py) | `collections` — specialised containers that replace hand-written bookkeeping. |
| 2 | [`functools_tools.py`](functools_tools.py) | `functools` — tools that take functions and give back better functions. |
| 3 | [`datetime_basics.py`](datetime_basics.py) | `datetime` — dates, times, durations and time zones. |
| 4 | [`regex_basics.py`](regex_basics.py) | `re` — regular expressions for finding and rewriting text patterns. |
| 5 | [`logging_basics.py`](logging_basics.py) | `logging` — messages with levels, sources and timestamps, instead of print. |

```bash
python3 basics/13_standard_library/collections_module.py
```
