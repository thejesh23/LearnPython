# 04 · Strings

Slicing, formatting, the everyday methods, Unicode and bytes, text tools.

Read the files in this order; each one runs on its own:

| # | File | What it teaches |
|---|------|-----------------|
| 1 | [`slicing.py`](slicing.py) | Slicing — `s[start:stop:step]`, the single most useful Python syntax. |
| 2 | [`common_methods.py`](common_methods.py) | The string methods you will reach for daily. |
| 3 | [`f_strings.py`](f_strings.py) | f-strings — formatting by embedding expressions directly in the literal. |
| 4 | [`multiline_and_raw.py`](multiline_and_raw.py) | Triple-quoted strings, raw strings, and escape sequences. |
| 5 | [`text_tools.py`](text_tools.py) | Tools for building and reshaping text: join, textwrap, translate and string. |
| 6 | [`unicode_and_bytes.py`](unicode_and_bytes.py) | Unicode text and raw bytes: two different types, and how to cross between them. |

```bash
python3 basics/04_strings/slicing.py
```
